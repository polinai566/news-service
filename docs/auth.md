# Ролевая модель

## Незарегистрированный пользователь

Чтобы пользователь получил роль ему необходимо зарегистрироваться через ручку Register User. По умолчанию при регистрации пользователь получает роль **user**.

Любой пользователь, который пройдёт регистрацию, может через ручку Login пройти авторизацию и получить refresh и JWT token. Также, обладая валидным refresh токеном, любой пользователь может обновить сессию, в которой привязан этот refresh token.

## Роль user

Пользователь с ролью **user** может:

- смотреть информацию *о себе* (Get User By Id)
- изменять данные *о себе* (Update User)
- удалять *свой* аккаунт (Delete User)
- получать список новостей (Get News) и получать новость по ID (Get News By Id)
- создавать комментарии к новостям (Create Comment), получать их список (Get Comments), получать по ID (Get Comment By Id), изменять *свои* комментарии (Update Comment) и удалять *свои* комментарии (Delete Comment)
- получать информацию о *своей* сессии (Get Session By Id)
- удалять *свою* сессию (Logout)

## Роль author

Пользователь с ролью **author** может всё, что может пользователь с ролью **user**, а также:

- создавать новости (Get News)
- удалять *свои* новости (Delete News)

## Роль admin

Пользователь с ролью **admin** может всё, что может пользователь с ролью **author**, а также:

- смотреть список всех пользователей (Get Users) и всех сессий пользователей (Get Sessions), а также *любого* пользователя и сессию по ID
- изменять и удалять *любых* пользователей, *любые* новости и комментарии
